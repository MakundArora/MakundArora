### Featured project

**[change-review-agents](https://github.com/MakundArora/change-review-agents)**: A multi-agent
LangGraph system that reviews IT change requests and decides to **act, escalate or return** them.
Deterministic agents do the auditable checks, and an LLM critic can escalate a change to a human
but never approve one. On 150 synthetic change requests it reaches 92% decision accuracy, and its
errors are all semantic cases, which is where the LLM critic is used.
